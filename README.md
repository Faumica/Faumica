# FAUMICA — Set Ciotole Rialzate in Legno di Bamboo e Ceramica

Sito web vetrina moderno, elegante e completamente responsive per il set di ciotole **FAUMICA** (Taglia Unica per gatti e cani di piccola e media taglia).

## Caratteristiche del Prodotto Presentate
- **Supporto in legno di bamboo** protetto da uno **strato di vernice impermeabile** per non rovinare il legno.
- **Piedini smontabili** ad incastro, pratici e perfetti per il trasporto e i viaggi.
- **Gommini antiscivolo** sotto i piedini per stabilità assoluta e protezione dei pavimenti.
- **Due ciotole in ceramica** (1 classica liscia + **1 ciotola antisoffocamento**) estraibili e **lavabili in lavastoviglie**.
- **Collegamento diretto allo Shop Amazon**: `https://amzn.eu/d/08ysLmCz`.

## File del Progetto
- `index.html` — Pagina vetrina con switcher fotografico nell'Hero (*Il Set / Cani / Gatti*), esploratore interattivo con hotspot (1–5), box acquisto diretto Amazon, barra sticky mobile per l'acquisto rapido, galleria reale, FAQ e contatti.
- `css/styles.css` — Stili responsive con palette legno bamboo, lino naturale e verde bosco.
- `js/app.js` — Interattività per selettore foto Hero, hotspot prodotto, FAQ, lightbox e validazione modulo contatti.
- `assets/images/` — Foto ufficiali del prodotto, foto reali con cane e gatto, e loghi FAUMICA.
